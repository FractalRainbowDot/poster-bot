# Poster Bot — домен публикаций

Домен одного владельца, который готовит посты и публикует их в один
Telegram-канал по запланированным слотам времени через бота.

## Language

**Пост**:
Единица содержимого для публикации: текст, медиа или их комбинация,
выходящая в канал одним сообщением или альбомом целиком.
_Avoid_: сообщение, материал, запись

**Отложенный пост**:
Пост без назначенной публикации; хранится, пока владелец не выберет дату
публикации или не удалит его.
_Синоним_: черновик — когда речь о ещё не завершённом содержимом поста.
_Avoid_: заготовка, шаблон

**Отложенное**:
Совокупность отложенных постов, которым ещё не назначена публикация.
_Avoid_: черновики, очередь публикаций

**Слот**:
Момент времени, доступный для планирования публикации: почасовые слоты
в настраиваемых границах дня либо отдельная будущая минута, выбранная владельцем.
_Avoid_: окно, интервал, расписание

**Запланированная публикация**:
Пост, подтверждённый владельцем на слот; доступен для редактирования и отмены
до начала отправки.
_Avoid_: задание, задача, очередь

**Источник**:
Исходное сообщение, из которого пост публикуется пересылкой без изменения содержимого.
_Avoid_: оригинал, цитата

**Копия**:
Пост, опубликованный как редактируемое собственное сообщение бота на основе источника.
_Avoid_: клон, дубликат

**Пропущенная**:
Запланированная публикация, не отправленная в свой слот; остаётся на паузе,
пока владелец не перепланирует её вручную.
_Avoid_: отложенная, просроченная

**Неопределённый результат**:
Исход отправки, который не удалось достоверно подтвердить; проверяется
владельцем вручную в канале, автоматически не повторяется.
_Avoid_: ошибка, сбой

**Журнал**:
Записи событий последних 30 дней для владельца, без содержимого постов и секретов.
_Avoid_: лог, история действий
